# Sunny orchard theme

Original artwork and a brighter casual farm-game treatment inspired by the user's Solitaire Grand Harvest reference. No reference game's branding or artwork is included.

The theme lives in `src/harvest-theme.css`. `src/board/materials.ts` changes only felt paint; polygon outlines, hole coordinates, radii, track counts, board sizing, and spacing are preserved. Actual server match state drives the turn and completed-game styling. Existing animal portraits, cards, game rules, and animations remain in use.

Artwork: `public/assets/harvest/orchard-background.png`, generated with the built-in image generation tool.

Final generation prompt:

> Use case: stylized-concept. Asset type: original background illustration for Angry Marbles browser board game. Create a landscape 1536x1024 polished cheerful casual mobile farm game background, lush orchard with round apple trees at far left and right edges, sunny rolling green hills, distant small red barn at upper right, honey-gold wooden fence toward lower edge, tiny daisies in lower corners, blue sky with soft fluffy clouds in top quarter, golden late-morning sunlight. Painterly 3D cartoon art, rounded plush forms, rich vibrant greens, warm soft highlights, charming high quality family game illustration. Composition: central 70 percent low-detail grassy clearing with soft grass color transitions; all detailed scenery confined to outer left/right edges and top 15 percent, so a large interactive board can cover center. No board, no marbles, no cards, no interface, no buttons, no text, no logos, no watermark. Original artwork, welcoming and playful, readable calm center.
